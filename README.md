# 💿 CD Player Era

Веб-плеер в эстетике **Y2K / kawaii** — крутящийся диск-микстейп с наклейками,
LED-бегущая строка, металлические кнопки управления и полка с дисками.
Музыка **генерируется прямо в браузере** через Web Audio API: у каждого диска
своя чиптюн-мелодия (лид + бас + перкуссия), поэтому не нужны никакие
аудиофайлы и нет проблем с авторскими правами.

## Структура проекта

```
Большая практика/
├── index.html          # разметка страницы
├── css/
│   └── style.css       # все стили (диск, стикеры, кнопки, анимации)
├── js/
│   ├── tracks.js       # таблица нот + список треков с мелодиями
│   └── player.js       # аудио-движок Web Audio + логика управления
├── server.rb           # маленький локальный статический сервер (UTF-8 safe)
├── .claude/
│   └── launch.json     # конфиг запуска сервера
└── README.md
```

## Как запустить

Нужен только **Ruby** (есть в macOS из коробки). Из папки проекта:

```bash
ruby server.rb 5500
```

Затем открыть в браузере:

```
http://localhost:5500/
```

> Почему свой `server.rb`, а не `python3 -m http.server`?
> В системе нет Python/Node, а встроенный в Ruby WEBrick падает на
> кириллице в имени папки «Большая практика». `server.rb` — крошечный
> сервер на сокетах, корректно работающий с UTF-8 путями. Порт можно
> сменить, передав другой аргумент: `ruby server.rb 8080`.

Файл `index.html` можно открыть и напрямую двойным кликом — плеер работает
без сервера, потому что все зависимости локальные, а шрифты берутся с
Google Fonts.

## Управление

| Действие            | Кнопка / клавиша            |
| ------------------- | --------------------------- |
| Играть / пауза      | ▶ / **Пробел**              |
| Следующий трек      | ⏭ / **→**                   |
| Предыдущий трек     | ⏮ / **←**                   |
| Перемешать          | 🔀 shuffle                  |
| Повтор              | 🔁 repeat                   |
| Выбрать диск        | клик по диску на полке      |

## Как добавить свой трек

Открой `js/tracks.js` и добавь объект в массив `TRACKS`:

```js
{
  title:"НАЗВАНИЕ ТРЕКА",        // бежит по LED-экрану
  label:"исполнитель",          // подпись
  sticker:"🎧",                 // эмодзи-стикер на диске-полке
  grad:"conic-gradient(...)",   // цвет диска на полке
  bpm:120, wave:"square",       // темп и тембр (square/triangle/sawtooth/sine)
  lead:["C5","E5","G5", ...],   // мелодия (ноты см. в объекте NOTE, "R" = пауза)
  bass:["C3","C3","G3", ...]    // басовая линия
}
```

## Технологии

- **HTML / CSS** — вёрстка и вся визуальная часть (без фреймворков).
- **Vanilla JavaScript** — логика плеера.
- **Web Audio API** — синтез мелодий в реальном времени.
- **Google Fonts** — Archivo Black, Gochi Hand, VT323.
